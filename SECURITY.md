# Säkerhet / Security

Hittar du ett säkerhetsproblem i doc-harbor-server? Rapportera det **privat** via GitHubs
[Report a vulnerability](https://github.com/walker42195/doc-harbor-server/security/advisories/new)
i stället för att skapa ett publikt ärende. Beskriv gärna hur problemet kan återskapas.

Found a security issue? Please report it **privately** via GitHub's
[Report a vulnerability](https://github.com/walker42195/doc-harbor-server/security/advisories/new)
instead of opening a public issue.

Säkerhetsrättningar görs i den senaste versionen. / Fixes are made in the latest release.
