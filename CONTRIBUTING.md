# Bidra / Contributing

Tack för att du vill hjälpa till! Ärenden och pull requests är välkomna.

- Beskriv vad ändringen löser och hur du har testat den.
- Håll ändringarna små och fokuserade.
- Genom att skicka ett bidrag godkänner du att det licensieras under
  **GNU AGPL v3.0**, samma licens som resten av projektet.

Thanks for helping out! Issues and pull requests are welcome. Describe what your change
fixes and how you tested it. By submitting a contribution you agree that it is licensed under
the **GNU AGPL v3.0**, the same license as the rest of the project.

Utvecklingen sker i ett internt repo och publiceras hit vid varje release, så godkända
bidrag förs in för hand och dyker upp i nästa version. /
Development happens in an internal repository that is published here with each release,
so accepted contributions are merged manually and appear in the next version.
